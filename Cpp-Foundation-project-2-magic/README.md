Твой выпускной экзамен начался. Перед тобой стоит котел, а на столе — 
куча подозрительных ингредиентов. Чтобы сварить "Зелье Истины", тебе 
нужно не просто бросать всё подряд, а использовать магию Python: 
Lambda, Map и Filter.

ТВОИ ЗАДАЧИ:

1. ОЧИСТКА (Filter): Избавься от гнилых и мертвых ингредиентов. 
   Магия не терпит разложения!
   
2. ИЗМЕЛЬЧЕНИЕ (Map): Все чистые ингредиенты должны быть обработаны 
   и подготовлены к варке.
   
3. ЭНЕРГИЯ (Math): Рассчитай точную температуру котла для каждого 
   элемента, используя математические константы.
