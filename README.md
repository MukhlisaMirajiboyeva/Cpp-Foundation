Путник, ты стоишь перед вратами Забытого Лабиринта. 
Говорят, здесь древние маги хранили свои знания в виде кода.

ТВОЙ ПУТЬ:
1. ПЕЩЕРА ГОБЛИНА: Сила случая (модуль random).
2. ВРАТА СФИНКСА: Мудрость древних свитков (работа с файлами).
3. ТРОННЫЙ ЗАЛ: Мастерство трансформации (Map/Filter).

ТВОИ ПРАВИЛА:
- Если здоровье (HP) упадет до 0 — твоя история закончится.
- Прогресс записывается в магический кристалл (save_game.dat).
- Запускай `dungeon_master.py`, чтобы начать или продолжить путь.

Будь осторожен: стены этого места слышат твои ошибки в синтаксисе...
