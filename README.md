Приветствую, Агент.

Корпорация OMEGA подверглась атаке неизвестного вируса. Система безопасности
частично разрушена, данные зашифрованы, а главный сервер перегревается.
Штатные программисты сбежали. Вся надежда на тебя.

ТВОЯ МИССИЯ:
Ты должен пройти сквозь 3 уровня защиты, восстановить доступ к системе
и найти вредоносный код в логах сервера.

----------------------------------------------------------------
🗺 КАРТА ЗАДАНИЙ
----------------------------------------------------------------

УРОВЕНЬ 1: ВХОД В СИСТЕМУ
📍 Где: Папка "Level_1" -> файл "login.py"
📝 Задача: Система аутентификации сломана. Исправь ошибку в коде, 
   чтобы получить доступ к защищенным секторам.

УРОВЕНЬ 2: ПОДБОР КЛЮЧА
📍 Где: Секретная папка (её имя ты узнаешь после прохождения 1 уровня)
📝 Задача: Архив с данными зашифрован пин-кодом (4 цифры). 
   Напиши скрипт для перебора паролей (brute-force), чтобы открыть архив.

УРОВЕНЬ 3: АНАЛИЗ УГРОЗ
📍 Где: Внутри архива -> файл "logs.txt"
📝 Задача: Среди тысяч строк системного мусора найти одну критическую
   запись о вирусе и сохранить её.

----------------------------------------------------------------
💰 СИСТЕМА ОЧКОВ И ПОДСКАЗКИ
----------------------------------------------------------------

1. Твой прогресс и очки сохраняются автоматически в файле "omega_status.dat".
   НЕ УДАЛЯЙ ЕГО!

2. За каждое выполненное задание ты получаешь баллы рейтинга.

3. ЗАСТРЯЛ?
   Запусти файл "get_hint.py" (находится в главной папке).
   Ты можешь купить подсказку за игровые очки.

----------------------------------------------------------------
🚀 С ЧЕГО НАЧАТЬ?
----------------------------------------------------------------

1. Открой папку "Level_1".
2. Открой файл "login.py" в редакторе кода (VS Code / PyCharm).
3. Прочитай задание в комментариях внутри кода.
4. Действуй.
