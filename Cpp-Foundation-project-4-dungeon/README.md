Путник, ты стоишь перед вратами Забытого Лабиринта. 
Говорят, здесь древние маги хранили свои знания в виде кода.

----------------------------------------------------------------
🗺️ ТВОЙ ПУТЬ:
----------------------------------------------------------------

1. ПЕЩЕРА ГОБЛИНА 👹
   Место, где правит хаос. Тебе нужно выжить, используя силу
   случая (модуль random) и циклы.

2. ВРАТА СФИНКСА 🦁
   Путь преграждает каменный страж. Твой ключ — мудрость 
   древних свитков (работа с файлами .txt).

3. ТРОННЫЙ ЗАЛ 🧙‍♂️
   Битва с Темным Магом. Отрази его заклинания с помощью 
   мастерства трансформации (Map/Filter).

----------------------------------------------------------------
🛡️ ТВОИ ПРАВИЛА:
----------------------------------------------------------------

- Если здоровье (HP) упадет до 0 — твоя история закончится.
- Твой рейтинг и прогресс записываются в магический кристалл 
  (файл save_game.dat). НЕ РАЗБЕЙ ЕГО!
- Запускай `dungeon_master.py`, чтобы продолжить путь.

⚠️ Будь осторожен: стены этого места слышат твои ошибки в синтаксисе...
   Лишний пробел или забытая скобка могут стоить тебе жизни!

----------------------------------------------------------------
🚀 С ЧЕГО НАЧАТЬ?
----------------------------------------------------------------

1. Проверь свой статус в `dungeon_master.py`.
2. Отправляйся в `levels/cave.py` для первого боя.
3. Ищи в файлах магические метки # ТВОЙ КОД ЗДЕСЬ.
