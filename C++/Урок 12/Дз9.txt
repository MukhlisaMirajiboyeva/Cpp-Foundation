Задача №1: «Мастер перестановки» (Работа со Стеком)
Тема: Передача адреса в функцию.

Задание:
1.Создай две переменные: int a = 10; и int b = 20;.
2.Напиши функцию swap(int* ptr1, int* ptr2), которая принимает адреса этих переменных.
3.Внутри функции, используя разыменование (*), поменяй значения переменных местами.
4.Выведи a и b в main до и после вызова функции.

Подсказка: Чтобы поменять значения, тебе понадобится третья временная переменная внутри функции (например, int temp).

Задача №2: «Гибкий список покупок» (Динамическая память)
Тема: Создание и удаление массива в Куче (new и delete).

Задание:
1.Спроси у пользователя: «Сколько товаров вы хотите купить?».
2.Создай динамический массив (в Куче) типа double именно такого размера.
3.В цикле попроси пользователя ввести цену каждого товара.
4.Посчитай общую сумму всех товаров.

Важно: В конце программы удали массив, чтобы не было утечки памяти.

Задача №3: «Шпионский шифр» (Указатели и Символы)
Тема: char, const и арифметика указателей.

Задание:
1.Создай строку: const char* message = "Hello";.
2.Создай указатель const char* ptr, который смотрит на начало этой строки.
3.Используя цикл while и инкремент указателя (ptr++), выведи каждую букву слова на новой строке.
4.Цикл должен остановиться, когда указатель встретит символ конца строки \0.

Подсказка: Условие цикла может выглядеть так: while (*ptr != '\0'). Это значит: «пока то, на что указывает ptr, не является концом строки».

💡 Советы по выполнию:
Для первой задачи: Помни, что при вызове функции нужно передавать адреса через значок амперсанда: swap(&a, &b);.
Для второй задачи: Не забудь использовать delete[] (с квадратными скобками), так как ты удаляешь массив, а не одну переменную.
Для третьей задачи: Помни, что const char* не даст тебе изменить буквы в "Hello", но позволит передвигать указатель ptr++.
