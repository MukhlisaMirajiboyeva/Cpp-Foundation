1. Что такое функция?
Функция — это именованный блок кода, который выполняет определенную задачу.
- Зачем нужны? Чтобы не писать один и тот же код многократно. Мы пишем его один раз внутри функции, а затем просто вызываем по имени.
- Аналогия: Это как «рецепт» или «скилл» героя в игре. Ты один раз прописываешь, что делает «Удар мечом», и потом просто нажимаешь кнопку активации.

2. Синтаксис и Объявление
Любая функция состоит из четырех частей:
1. Тип возвращаемого значения (что получим в итоге: int, double, string или void, если ничего).
2. Имя функции (с него начинается вызов).
3. Параметры в скобках (входные данные).
4. Тело функции в фигурных скобках { } (сам код).

3. Вызов функции
- Вызов — это команда программе перейти к выполнению кода функции.
- Чтобы вызвать функцию, нужно написать её имя и в скобках передать данные (аргументы).

Пример: printMessage(); или int result = sum(5, 10);

4. Параметры vs Аргументы
Часто эти понятия путают, но разница проста:
- Параметры — это «пустые ячейки» или переменные, которые мы указываем при создании функции (в её заголовке).
- Аргументы — это реальные значения, которые мы подставляем в эти ячейки в момент вызова.

Пример: В функции void square(int n), n — это параметр. А когда мы пишем square(5), то 5 — это аргумент.

5. Оператор return
Используется для двух целей:
1. Возврат результата: Чтобы передать вычисленное значение обратно в то место, где функцию вызвали.
2. Завершение работы: Как только программа доходит до return, выполнение функции прекращается (даже если после него был еще код).

Если тип функции void, return можно не писать (или писать просто return; для выхода).

6. Область видимости: Глобальные и Локальные переменные
Локальные переменные
- Создаются внутри функции (или внутри цикла/условия).
- Существуют только там, где созданы (между ближайшими { }).
- Когда функция заканчивается, локальные переменные «погибают».

Глобальные переменные
- Создаются вне всех функций (обычно в самом верху файла).
- Видны всем функциям в программе.

Важно: В профессиональном программировании их стараются использовать редко, так как любую глобальную переменную может случайно изменить любая функция, что ведет к ошибкам.
