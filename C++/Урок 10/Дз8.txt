Задача 1: Аналитик текста (Работа со std::string)
Условие: Напиши программу, которая просит пользователя ввести предложение. Программа должна:

- Вывести общую длину строки.
- Проверить, есть ли в этом предложении слово "школа" (используй .find()). Если есть — вывести индекс его начала, если нет — написать "Слово не найдено".
- Заменить в этом предложении все буквы 'а' на символ '@'.
- Вывести итоговую измененную строку.


Задача 2: Мастер чисел (Функции)
Условие: Напиши функцию calculate, которая принимает три параметра: два целых числа (int a, int b) и один символ (char operation).

- Если operation равен '+', функция должна вернуть сумму чисел.
- Если operation равен '-', функция должна вернуть разность.
- Если operation равен '*', функция должна вернуть произведение.
- Если передан любой другой символ — функция должна вернуть 0.

В основной программе (main): Попроси пользователя ввести два числа и знак операции. Вызови свою функцию и выведи результат на экран.

Бонусное задание (для отличников):
Напиши функцию, которая принимает std::string и возвращает эту же строку, но записанную задом наперед.

Подсказка: 
1. Создай внутри функции пустую строку string result = "";. 
2. Запусти цикл for, который идет от s.length() - 1 вниз до 0. 
3. Внутри цикла добавляй символы к result через += или push_back(). 
4. Верни result через return.
