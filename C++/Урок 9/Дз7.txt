Статические массивы (int a[N])
Задача 1: «Зеркало» Создайте статический массив из 8 целых чисел и заполните его любыми значениями. Напишите программу, которая меняет местами первый элемент с последним, второй с предпоследним и так далее (разворачивает массив «на месте»). Выведите результат на экран.

Задача 2: «Анализ температуры» Создайте массив, хранящий среднюю температуру за неделю (7 дробных чисел).

- Вычислите среднюю температуру за всю неделю.
- Подсчитайте, сколько дней температура была выше этой средней отметки.

Динамические массивы (std::vector)
Задача 3: «Умный фильтр» Создайте пустой вектор целых чисел.

- Попросите пользователя вводить числа по одному. Если введено число 0, ввод должен прекратиться.
- После окончания ввода удалите из вектора все отрицательные числа (используйте метод .erase()).
- Выведите итоговый список чисел и его новый размер (.size()).

Задача 4: «Пересменка в очереди» Дан вектор с именами людей в очереди: {"Олег", "Иван", "Анна", "Мария"}.

- Добавьте в начало очереди нового человека с именем "Борис" (используйте .insert() и .begin()).
- Удалите из очереди "Ивана", зная, что он стоит вторым (индекс 1).
- Добавьте в конец очереди "Елену".
- Выведите финальный список имен через запятую.
