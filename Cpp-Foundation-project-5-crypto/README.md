Агент, в архивах Ватикана найдено зашифрованное письмо Леонардо 
да Винчи. Похоже, великий мастер использовал свои технические 
знания, чтобы скрыть секрет вечного двигателя.

ТВОИ ЗАДАЧИ:

1. ЗЕРКАЛЬНЫЙ ЩИТ (mirror_shield.py): Великий Леонардо писал 
   справа налево. Тебе нужно развернуть его строки.

2. ШИФР МАСТЕРА (caesar_cipher.py): Дешифруй послание, используя 
   математические расчеты сдвига.

3. СБОРКА КЛЮЧА (key_collector.py): Собери фрагменты кода, 
   разбросанные по разным файлам, в одну финальную фразу.
