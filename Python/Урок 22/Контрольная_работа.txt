Блок 1. Функции (def)
Вопросы:
1. Чем отличается print() внутри функции от оператора return?
2. Что такое «аргументы по умолчанию» и как их записывать?

Задачи:
• Задача 1: Напиши функцию is_even(number), которая возвращает True, если число четное, и False, если нечетное.
• Задача 2: Напиши функцию describe_person(name, age=18), которая выводит фразу: "Имя: [name], Возраст: [age]". Проверь её, вызвав один раз только с именем, а второй раз — с обоими аргументами.

Блок 2. Модули и библиотеки (math, random)
Вопросы:
1. В чем разница между import math и from math import sqrt?
2. Как создать свой собственный модуль и подключить его к основной программе?

Задачи:
• Задача 1: С помощью модуля random создай программу «Лотерея»: программа должна выбрать 3 случайных числа из списка [10, 20, 30, 40, 50] и вывести их на экран.
• Задача 2: Используя модуль math, напиши программу, которая запрашивает радиус круга и вычисляет его площадь (S = \pi \times R^2), округляя результат вниз до ближайшего целого (используй math.floor).

Блок 3. Работа с файлами (with, open, modes)
Вопросы:
1. Что произойдет с данными в файле, если открыть его в режиме 'w', когда в нем уже что-то написано?
2. Зачем нужен метод f.seek(0) при работе с файлами?
3. В чем преимущество использования with open(...) перед обычным open(...)?

Задачи:
• Задача 1: Напиши программу, которая спрашивает у пользователя 3 его любимых фильма и записывает их в файл movies.txt (каждый фильм с новой строки).
• Задача 2: Напиши программу, которая читает файл movies.txt, добавляет к названию каждого фильма номер (например, "1. Inception") и выводит результат в консоль.

Блок 4. Лямбда, Map и Filter
Вопросы:
1. Почему результат map(lambda...) нужно оборачивать в list()?
2. В каких случаях лучше использовать обычную функцию def вместо lambda?

Задачи:
• Задача 1: Дан список чисел: numbers = [1, 5, 8, 10, 13, 20]. Используй filter и lambda, чтобы оставить только те числа, которые делятся на 5.
• Задача 2: Дан список цен в строковом формате: prices = ["100$", "200$", "500$"]. Используй map и lambda, чтобы убрать знак $ из каждой строки и превратить их в целые числа (int).
• Задача 3 (Комбо): Напиши в одну строку код, который возьмет список чисел, оставит в нем только положительные (больше 0) и возведет их в квадрат.
