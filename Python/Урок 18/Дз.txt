1. Задача «Организатор Вечеринки» (Списки)
Легенда: Вы организуете IT-тусовку. Вам нужно управлять списком гостей.
Создайте список guests, в котором уже есть 3 имени: ['Алишер', 'Бекзод', 'Сардор'].
- Опоздавшие: С помощью append добавьте в конец списка 'Давид'.
- VIP-гость: С помощью insert добавьте 'Мария' на самое первое место (индекс 0).
- Группа друзей: У вас есть второй список new_friends = ['Елена', 'Фаррух']. Добавьте их всех в основной список одним махом (используйте extend).
- Отмена: 'Сардор' не сможет прийти. Удалите его из списка по имени (remove).
- Сортировка: Отсортируйте список гостей по алфавиту (sort).
- Финал: Выведите на экран итоговый список и количество гостей (используйте len).

- Срез: Получите новый кортеж, содержащий только Код и Имя (первые два элемента).
- Взлом: Попробуйте изменить Код агента (первый элемент) на "000".
Напишите в комментарии к коду, какая ошибка появилась.

Лазейка: Агент получил новое оружие. Обратитесь к списку внутри кортежа (индекс 2) и добавьте туда "Гаджет-ручка".

Почему это сработало, если кортеж неизменяем? Напишите краткий ответ в комментарии.

3. Задача «Склад Электроники» (Словари)
Легенда: У вас есть словарь, описывающий характеристики ноутбука.

Создайте словарь laptop:

laptop = {
    "brand": "MacBook",
    "model": "Air M2",
    "ram": 8,
    "price": 1200
}
- Апгрейд: Измените значение ram на 16.
- Новая деталь: Добавьте в словарь новый ключ "color" со значением "Silver".
- Продажа: С помощью метода pop() удалите ключ "price" и сохраните его значение в переменную sold_price. Выведите: "Товар продан за [цена] долларов".
- Инвентаризация: С помощью цикла for пройдитесь по словарю (используя .items()) и выведите все характеристики в формате: Характеристика: [Ключ] | Значение: [Значение]

4. Задача «Слияние Баз Данных» (Преобразование)
Легенда: Учитель случайно записал имена студентов в один список, а их оценки за экзамен — в другой. Нужно соединить их.

Даны два списка:
students = ["Алина", "Тимур", "Жасмин", "Руслан"]
grades = [5, 3, 4, 5]
- Создание базы: Используя функцию zip() и dict(), создайте словарь grade_book, где ключи — имена, а значения — оценки.
- Анализ: Найдите и выведите имя студента с максимальной оценкой (подсказка: max(grade_book, key=grade_book.get) — это задание со звездочкой, попробуйте найти решение или используйте просто max по оценкам).
- Экспорт: Преобразуйте итоговый словарь обратно в список кортежей (используя .items() и list()) и выведите его.

- Программа должна превратить строку в список слов (метод string.split()).
