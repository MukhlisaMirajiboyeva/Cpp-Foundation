📝 Конспект: Работа с файлами в Python
Работа с файлом всегда состоит из трёх этапов:

Открыть (open)
Сделать дело (прочитать или записать)
Закрыть (close или доверить это with)

Главный инструмент: Контекстный менеджер with
Мы всегда используем with, потому что он сам закрывает файл, даже если программа выдаст ошибку.

with open("file.txt", "mode") as f:
    # работаем с файлом


🔍 Подробный разбор режимов (mode)
Режим — это «цель», с которой мы открываем файл.

1. Основные режимы:
'r' (Read / Чтение):

Для чего: Только посмотреть, что внутри.
Особенность: Если файла не существует — Python выдаст ошибку.
Курсор: В самом начале.

'w' (Write / Запись):

Для чего: Записать данные с нуля.
Особенность: ⚠️ Внимание! Если файл уже был, он полностью стирается (очищается) при открытии. Если файла нет — создается новый.

'a' (Append / Дозапись):

Для чего: Добавить что-то в конец файла.
Особенность: Старое содержимое остается на месте.
Курсор: Сразу прыгает в конец файла.

'x' (Exclusive / Создание):

Для чего: Создать новый файл и записать в него.
Особенность: Если файл уже существует — выскочит ошибка. Это защита, чтобы случайно не стереть старый файл через 'w'.

➕ Режимы с плюсом (Обновление)
Символ + превращает режим в «комбо»: он позволяет и читать, и писать одновременно.

'r+' (Чтение + Запись):

Самый популярный "плюс".
Плюс: Можно читать файл и вносить в него правки.
Минус: Ошибка, если файла нет.
Важно: Пишет поверх старого текста (заменяет символы по ходу движения курсора).

'w+' (Запись + Чтение):

Опасность: Как и обычный 'w', он стирает всё сразу при открытии!
Зачем нужен? Чтобы создать пустой файл, что-то в него записать и тут же прочитать (не закрывая файл).

'a+' (Дозапись + Чтение):

Позволяет дописывать в конец и читать файл.
Нюанс: Так как запись идет в конец, для чтения нужно будет «перемотать» курсор в начало командой f.seek(0).

🛠 Главные методы (что мы делаем с файлом)
f.read() — прочитать всё содержимое одной длинной строкой.
f.readlines() — прочитать всё и превратить в список строк (удобно для циклов).
f.write("текст") — записать текст. (Помни: Python не ставит Enter сам, нужно добавлять \n).
f.seek(0) — переместить "курсор" (указатель) в начало файла. Полезно в режимах с +.

💡 Пример:
# Дописываем новую строку и читаем весь файл
with open("notes.txt", "a+", encoding="utf-8") as f:
    f.write("Новая заметка\n") # Дописали в конец
    
    f.seek(0)                # Вернулись в начало, чтобы прочитать
    print(f.read())          # Вывели всё на экран

Запоминалка:

r — Read (смотрю).
w — Wipe & Write (стираю и пишу).
a — Add (добавляю в хвост).
+ — хочу и читать, и писать сразу.
