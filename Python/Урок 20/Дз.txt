🏠 Домашнее задание: «Файловый менеджер»
Совет перед началом:
Не забывайте указывать encoding="utf-8", чтобы русский текст отображался корректно.
Используйте конструкцию with open(...), чтобы файлы закрывались автоматически.

Задача 1. «Книга жалоб и предложений» (Режим a)
Вы пишите программу для магазина. Пользователи могут оставлять отзывы, и они должны сохраняться в файл вечно, не стирая старые.

Задание:
- Спросите у пользователя имя (input).
- Спросите у пользователя текст отзыва (input).
- Откройте файл reviews.txt в режиме дозаписи ('a').
- Запишите данные в формате: Имя: Отзыв.
Важно: Не забудьте добавить перенос строки \n в конце, чтобы каждый новый отзыв начинался с новой строчки.

Пример работы:
Введите имя: Антон Ваш отзыв: Всё супер! Программа молча сохраняет это в файл.

Задача 2. «Умный калькулятор» (Режим r)
Бухгалтер прислал вам файл prices.txt, где в столбик записаны цены на товары. Вам нужно посчитать общую сумму.
Подготовка: Создайте вручную (через блокнот или через VScode) файл prices.txt и напишите туда числа в столбик:

100
50
200
350

Задание:
- Напишите скрипт, который открывает prices.txt в режиме чтения ('r').
- С помощью цикла пройдитесь по каждой строке.
- Превратите строку в число (int) и прибавьте к общей сумме (total_sum).
- Выведите итоговую сумму на экран.

Общая стоимость товаров: 700

Задача 3. «Редактор черновиков» (Чтение + Запись)
Писатель набросал список идей, но некоторые строки начинаются со слова "Удалить". Нужно переписать хорошие идеи в чистый файл.

Подготовка: Создайте файл draft.txt с таким содержимым:

Удалить: скучная глава
Герой находит меч
Удалить: плохой диалог
Битва с драконом
Свадьба принцессы

Задание:
- Откройте draft.txt для чтения.
- Откройте новый файл clean_copy.txt для записи ('w').
- Читайте черновик построчно.
- Если строка НЕ начинается со слова "Удалить", записывайте её в новый файл.
- В конце программа должна вывести: "Чистовик готов!".

(Подсказка: используйте метод строки .startswith("Удалить") или проверку if "Удалить" not in line).
