Задача 1: Цикл for (Известное количество повторений)
Название: «Генератор отчетов» Суть: Отработать функцию range() и проверку условий внутри перебора.
Задание: Пользователь вводит целое число N. Напишите программу, которая перебирает все числа от 1 до N (включительно). Для каждого числа программа должна решить:
- Если число делится на 3 без остатка — вывести: "Число [X] — делится на 3".
- Если число НЕ делится на 3 — вывести: "Число [X] — обычное".
Дополнительное условие: Если число равно 13 (несчастливое), программа должна написать "Пропускаем..." и не выводить про "обычное".

Пример:
Введите число: 4
>> Число 1 — обычное
>> Число 2 — обычное
>> Число 3 — делится на 3
>> Число 4 — обычное


Задача 2: Цикл while (Работа до выполнения условия)
Название: «Копилка» Суть: Отработать цикл, который работает неизвестное число раз (пока не накопим сумму).
Задание: Вы хотите накопить на новый телефон. Он стоит, например, 100 000 сум (эту сумму вводит пользователь в начале). Напишите программу, которая спрашивает: "Сколько откладываем сегодня?".
- Вы вводите сумму, она добавляется в копилку.
- Программа пишет: "Сейчас в копилке: [Сумма]".
- Цикл должен продолжаться ПОКА накопленная сумма меньше цены телефона.
- Как только накопили — цикл останавливается, и программа пишет: "Ура! Накопили [Всего] сум.".

Пример:
Цена телефона: 100 000 00
>> Сколько откладываем? 300000
Сейчас в копилке: 300000
>> Сколько откладываем? 500000
Сейчас в копилке: 800000
>> Сколько откладываем? 300000
Сейчас в копилке: 110000000
Ура! Накопили 110000000 руб.
