⚡ 1. Лямбда-выражения (Анонимные функции)
Это функции-однодневки. Нужны, когда действие простое и имя функции придумывать лень.

Синтаксис: lambda параметры: результат
Параметры: что функция принимает (через запятую).
Результат: что функция возвращает (пишется без return).

Примеры:

lambda x: x + 10 — прибавить 10.
lambda a, b: a * b — умножить два числа.
lambda s: s.lower() — перевести строку в нижний регистр.

Пример:
# Слово lambda | Аргумент n | Двоеточие | Что вернуть (n * n)
square = lambda n: n * n

print(square(5)) # Вывод: 25

Разбор:
lambda: Cлово, которое говорит питону: «Сейчас будет быстрая функция».
n: Это входной параметр (то, что летит в скобки). Их может быть сколько угодно (через запятую), или не быть вообще.
":": Это граница. Слева — входы, справа — выходы.
n * n: Это то, что функция делает. Важно: тут не нужно писать слово return. Лямбда сама понимает, что результат выражения справа надо вернуть.

Ограничение: В лямбда-функцию можно впихнуть только одно действие (одно выражение). Если нужно сделать что-то сложное в 10 строк — используй обычный def.

🏭 2. Функция map() (Преобразование)
Применяет одну и ту же функцию к каждому элементу списка. Количество элементов на выходе не меняется.

Синтаксис: list(map(функция, список))

Пример: Возвести все числа в списке в квадрат.

nums = [1, 2, 3, 4]
squares = list(map(lambda x: x**2, nums))
# Результат: [1, 4, 9, 16]

Пример:
dollars = [10, 20, 50]
sums = list(map(lambda x: x * 12800, dollars))
print(sums)

⚠️ Очень важный момент про list()
Ты заметил, что я написала list(...) вокруг map?  Если написать просто print(map(...)), Python скажет: <map object at 0x...>. Дело в том, что map — ленивый. 
Он не делает работу сразу. Он просто «запоминает план работы». Чтобы заставить его реально выдать список результатов, нужно пнуть его командой list().

🧹 3. Функция filter() (Фильтрация)
Если map меняет элементы, то filter отбирает их. Представь охранника в клубе. 
Он смотрит на каждого человека и говорит либо «Да (True)» — проходи, либо «Нет (False)» — уходи.
То есть отбирает элементы из списка по условию. На выходе элементов обычно меньше, чем на входе.

Синтаксис: list(filter(функция-условие, список))
Функция-условие должна возвращать True (оставить) или False (удалить).

Пример: Оставить только числа больше 10.

nums = [5, 12, 8, 21, 3]
big_nums = list(filter(lambda x: x > 10, nums))
# Результат: [12, 21]


🎓 Главные правила (Шпаргалка)
Всегда пиши list(): Результаты map и filter — это специальные объекты («обещания» сделать работу). Чтобы увидеть их как обычный список, оберни их в list().
Слева направо: Внутри скобок сначала идет что делать (lambda), а потом с чем делать (твой список).
Краткость: Если в функции больше одного действия или есть условия if/else (сложные), лучше используй обычный def.
